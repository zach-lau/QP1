# A Critique and Simulation Study on Extended Ensemble Kalman Methods
This repository provides code and experiments analyzing the Gibbs ensemble
Kalman filter (GEnKF) and particle ensemble Kalman filter (PEnKF) proposed
by Katzfuss et al. (2020). The notebooks in `code/simulation` contain 
individual runs, while `code/simulation/replicate.py` contains the code for 
the full simulation study.

## Reference
Katzfuss, M., Stroud, J. R., and Wikle, C. K. (2020). Ensemble Kalman methods
for high-dimensional hierarchical dynamic space-time models. *Journal of the
American Statistical Association*, 115(530), 866–885.
[doi:10.1080/01621459.2019.1592753](https://doi.org/10.1080/01621459.2019.1592753)
